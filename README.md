# Interactive Rating Component

A solution to the [Frontend Mentor](https://www.frontendmentor.io) "Interactive rating component" challenge, built with plain HTML, CSS and JavaScript.

## Preview

| Rating state | Thank-you state |
|---|---|
| ![Rating state](./screenshots/rating-state.png) | ![Thank-you state](./screenshots/thank-you-state.png) |

## Features

- Choose a rating from 1 to 5
- Hover and focus states on the rating buttons and the submit button
- Submitting swaps the card for a "Thank you" screen that shows the selected rating

## Built with

- HTML5
- CSS3 (custom styling, [Outfit](https://fonts.google.com/specimen/Outfit) font)
- Vanilla JavaScript

## Project structure

```
├── index.html
├── style.css
├── script.js
├── images/    # icons and illustration
└── design/    # Frontend Mentor design reference images
```

## Run locally

Clone the repo and open `index.html` in your browser. No build step or dependencies are needed.
